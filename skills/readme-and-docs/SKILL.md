# README and docs

Apply when a project is created or its usage changes.

README.md, in this order:
1. One sentence: what it is and who it is for.
2. Install: the exact commands.
3. Run: the exact command, with one real example and its output.
4. Usage: the options or the main functions, each with an example.
5. Configuration: every setting, its default, and where it lives.
6. Development: how to run the tests.

Keep it honest: only features that exist; update it in the same change as the code. Docstrings on public functions: what it does, its inputs and outputs, and what happens on bad input. No doc for the obvious.
