# Skills

A skill is a folder with a `SKILL.md`: a short YAML header (`name`, `description`) and the instructions the models follow
when the skill is enabled. Enabled skills are added to every model call in chats, the prompt studio and Builds, so keep
the enabled set small and each skill under a page. Turn skills on and off, add your own, or write a new one in
Settings › Skills. The built-in set is a starting point; edit it freely.
